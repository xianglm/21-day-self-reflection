# 21-Day Self-Reflection Companion · 21天自我认知陪伴

> 一个基于权威心理学理论的 21 次对话式自我探索 Skill。通过每日引导对话与结构化记录，在周期结束时输出当前状态总结、阶段性自我观察画像与可落地、可验证的行动建议。

**版本**：V1.1　|　**定位**：自我探索陪伴工具，**不是心理治疗、心理诊断或危机干预**

---

## 它是什么

围绕"我是谁"这一核心问题，开展连续 **21 次结构化对话**（每天一次为佳，中断可续）。每次对话后自动记录要点与情绪/能量打分；第 21 次对话后，综合全部记录，基于心理学理论生成一份包含**状态总结、自我观察画像、阶段性建议**的报告，并在之后提供回访闭环。

## 它不是什么

- ❌ 不是心理咨询、心理治疗或精神科诊疗；
- ❌ 不做人格测评或心理诊断；
- ❌ 不处理急性心理危机（自伤/伤他、躁狂发作、精神病性症状、急性创伤反应等）；
- ❌ 不替代现实中的人际关系与专业支持。

## 核心特性

- **跨会话连续记录**：以 `state.json` 为权威状态，任何新会话都能无缝续接，不依赖单次对话记忆；
- **首次知情同意与扩展筛查**：13 题筛查覆盖年龄、治疗/服药/诊断史、既往自伤史、近两周状态与急性症状，分四档分流（标准版 / 恢复优先版 / 暂缓转介 / 未成年人特殊处理）；
- **每日情绪能量监测与自动降档**：连续恶化触发阈值时自动暂停沉重话题、转入恢复模式并建议专业支持；
- **证据分级的报告**：所有画像结论标注证据强度（🟢较可靠 / 🟡初步观察 / ⚪信息不足），防止巴纳姆效应与过度解读；
- **状态与特质强制区分**：明确区分"近期可变状态"与"相对稳定倾向"，不把短期压力误写成人格；
- **可落地可验证的建议**：每条建议含理论依据 + 具体动作（频次/时长）+ 验证方式（锚定每日打分或可观察行为）；
- **数据可导出可删除**：用户可随时导出全部记录或要求彻底删除。

## 工作流程

```
首次对话
  ├─ 知情同意（非治疗 / 数据位置 / 可删除 / 危机处理）
  ├─ 扩展筛查（13题，四档分流）
  ├─ 危机资源本地化（当地热线 / 医院 / 紧急联系人）
  └─ 基线打分（心情 / 能量 / 生活满意度 / 身份清晰度）
      ↓
Day 1 ~ Day 21（21次对话）
  ├─ 读档续接 → 当日话题引导 → 当日心情/能量打分
  ├─ 恶化监测（触发则自动降档）
  └─ 写入日志（用户原话 + 经确认的观察）
      ↓
Day 21 复测四项分数 → 生成总结报告
  ├─ 当前状态总结（含分数趋势与风险标记）
  ├─ 阶段性自我观察画像（状态区 / 倾向区）
  ├─ 3~5 条可落地建议
  └─ 后续安排与安全资源
      ↓
回访（报告后约1周、3周，可选）
  └─ 检查建议执行情况，保留有效动作、替换无效动作
```

## 理论基础

所有判断逻辑锚定以下权威理论，并在报告中标注依据：

| 理论 | 学者 | 用途 |
|---|---|---|
| 心理社会发展 / 自我同一性 | Erik Erikson | 同一性探索期的正常化 |
| 同一性状态模型 | James Marcia | 达成 / 延缓 / 早闭 / 扩散四状态 |
| 自我概念与不一致 | Carl Rogers | 现实自我 vs 理想自我 |
| 自我差距理论 | E. Tory Higgins | 失望型 vs 焦虑型差距的区分应对 |
| 意义疗法 | Viktor Frankl | 意义的三种来源（创造 / 体验 / 态度） |
| PERMA 幸福模型 | Martin Seligman | 积极情绪 / 投入 / 关系 / 意义 / 成就 |
| 大五人格 | Big Five (OCEAN) | 仅作观察性描述，非量表诊断 |
| 基本价值观理论 | Shalom Schwartz | 价值观识别与冲突对 |
| 执行意图 | Peter Gollwitzer | 建议的"如果…那么…"落地策略 |
| 心流 | Mihaly Csikszentmihalyi | 投入状态识别 |

## 适用与不适用

**适用**：18 岁及以上、无急性心理危机、知情同意的成年人，用于阶段性自我觉察与行动规划。

**不适用 / 应暂缓并转介**：
- 未成年人（需监护人知情同意，仅可在专业人员陪同下使用轻量话题）；
- 正在接受心理治疗或精神科治疗者（须告知治疗师，治疗师反对即暂停，且本工具不替代治疗、不调药）；
- 双相情感障碍躁狂/轻躁狂期、精神病性症状、急性创伤/PTSD 急性期、进食障碍急性期、物质中毒/戒断期、明显解离状态、近期自杀未遂者；
- 任何出现自伤/伤他念头的情况——此时应立即联系心理援助热线或就医。

## 数据与隐私

- 对话与日志保存在运行该 Skill 的 AI 服务的**云端运行环境**中（非用户设备本地），具体数据处理以所用平台的隐私政策为准；
- 建议对话中**不要提供**身份证号、详细住址、电话号码等不必要的敏感身份信息；
- 用户可随时要求**导出**全部记录（state.json / journal.md / final-report.md）或**彻底删除**整个数据目录。

## 安装与使用

将本目录放入支持 Skill 机制的 AI Agent 的 `user_skills`（或等价）目录下，重启/刷新后即可被识别。触发语例如："开始第一天的我是谁对话""继续自我探索""生成21天总结""回访建议执行情况""导出/删除我的记录"。
